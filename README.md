# 🧰 BITools — Herramientas para desarrolladores BI

**BITools** es un repositorio de herramientas web ligeras, gratuitas y 100% locales, pensadas para agilizar el día a día de quienes trabajan con **Power BI** y visualización de datos. Cada herramienta es un archivo HTML independiente: ábrelo en tu navegador y úsalo al instante, sin instalar nada y sin subir tus datos a ningún servidor.

---

## 🚀 ¿Qué encontrarás aquí?

### 🖼️ Image Extractor
> Extrae todas las imágenes de un archivo `.pbix`

Arrastra tu archivo `.pbix` (que en realidad es un ZIP) y esta herramienta extrae automáticamente **todas las imágenes** que contiene: PNG, JPG, GIF, BMP, SVG, WEBP, ICO, TIF y TIFF, incluidas las que están embebidas dentro de archivos JSON.

- ✅ 100% local: nada se sube a ningún servidor
- 📊 Estadísticas por formato y peso total
- 🔍 Búsqueda y filtros por tipo de archivo
- ⬇️ Descarga individual o todas en un ZIP
- 📋 Copia en Base64 con un clic

**Ideal para:** recuperar logos, iconos o recursos visuales de un reporte sin tener que abrir Power BI Desktop.

---

### 🎨 Palette Extractor v2
> Extrae paletas de colores profesionales desde cualquier imagen

Sube una imagen (PNG, JPG, SVG, WEBP) y obtén una **paleta de colores** lista para usar en tus reportes. Elige cuántos colores quieres (3, 5, 8 o 10) y el método de extracción:

- **Cuantización** — colores dominantes por agrupación
- **K-Means** — agrupación por similitud de color
- **LAB Perceptual** — colores que se ven mejor al ojo humano

Ordena por luminosidad, dominancia, tono o saturación, y filtra por vibrantes, apagados, oscuros o claros. Incluye una **vista previa de dashboard** para ver cómo lucirán tus colores en un reporte real.

**Exporta a:** JSON para Power BI, tema completo, lista HEX, variables CSS o imagen de la paleta.

**Ideal para:** crear temas y paletas de marca coherentes para tus dashboards.

---

### 📐 SVG → DAX Measure
> Convierte código SVG en una medida DAX reutilizable

Pega tu código SVG y esta herramienta lo convierte al instante en una **medida DAX** lista para usar en Power BI. Incluye vista previa en vivo, limpieza automática del SVG (elimina scripts, estilos y atributos innecesarios) y copia de la medida con un clic.

- ⚡ Generación automática y en vivo
- 🧹 Limpieza de SVG para un código más seguro y ligero
- 📋 Copia la medida DAX directamente

**Ideal para:** crear iconos y visuales personalizados con SVG dentro de Power BI.

---

## 🛠️ Cómo usar

1. Descarga el archivo HTML de la herramienta que necesites (o clona el repositorio).
2. Ábrelo con doble clic en tu navegador (Chrome, Edge, Firefox…).
3. Listo: funciona sin conexión y sin instalar nada.

> 💡 **Privacidad:** todas las herramientas procesan tus archivos **localmente en tu navegador**. Tus datos nunca salen de tu equipo.
